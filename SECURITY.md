# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately:

- Use [GitHub Private Vulnerability Reporting](https://github.com/hyt315/network-slow-diagnosis/security/advisories/new)
- Or open a [Discussion](https://github.com/hyt315/network-slow-diagnosis/discussions)

**Do not report security vulnerabilities through public GitHub issues.**

We aim to respond within 5 business days.

## Supported Versions

As an AI Agent Skill, only the latest released version is actively supported.
